# 高血压食养资料检索样本

本轮已完成离线 RAG 的清理、结构切分、证据定位与检索验证部分。未调用模型生成医学回答。

## 处理范围

原文件为56页《成人高血压食养指南（2023年版）》，本轮处理PDF物理第3—10页，对应印刷页1—8。
封面目录及附录食谱表格均不进入索引。版本是否现行、AI使用及再分发许可仍待确认。
原文和既有业务数据库未改动。处理产物全部保存在此独立目录，不自动进入网页或Craft正式问答。

## 实际实现

1. 校验原PDF的SHA256，并保存文本提取快照哈希和处理版本。
2. 按提取文本的行偏移保留每段raw_quote，清除8个页码和1个重复标题，另记录清理日志。
3. 识别中文章节标题，以章节整体作为检索块；跨页延续同一章节，纯标题不单独作为检索结果。
4. 生成9个块，152—926字符，合计4173字符。未强行凑到固定窗口，也未添加机械重叠。
5. 检索表示去除排版空白，使用中文双字词项与英文数字词项的BM25；展示及校验依据仍是逐字raw_quote。
6. 每块绑定文档ID、来源URL、文件哈希、章节路径、物理页码、印刷页码和原提取文本行偏移。
7. 所有块review_status=pending、generation_allowed=false；只输出证据检索预览。

行偏移定位到 pages.json 中对应页的提取文本，不是PDF字节偏移或屏幕坐标。
标记不会自动限制外部程序；本CLI本身不包含生成步骤，现有正式问答也不加载该目录。

## 质量记录

已逐页查看第3—10页渲染图，并检查检索关键段落。此检查是技术核对，不构成医学专业审核。

- PDF第6—7页的减钠增钾章节保持为同一块，肾功能限制未因换页脱离正文。
- 第4页脚注在解析顺序中穿插正文，尚未重建脚注关联，相关块带质量标记。
- 第8页BMI单位含上标，提取文本不保证保留版式语义，需对照原PDF。
- 第6页包含图示，未做图片OCR；同页正文列出了五项原则。
- 附录跨页表格未处理，不能声称全文件完成结构化。

## 复现

在D:\demo执行，以下脚本仅使用标准库，读取前期已提取的pages.json：

```powershell
python rag_pipeline.py build
python rag_pipeline.py search --question "肾功能不全者补钾前需要注意什么？"
python -m unittest -v
```

## 文件说明

- chunks.json：检索块和逐字引用定位。
- clean_pages.json：保留行结构的清理正文。
- cleaning_log.json：移除操作及原文偏移。
- build_report.json：处理范围、规模及限制。
- evaluation.json：逐题检索结果和基线对比。
