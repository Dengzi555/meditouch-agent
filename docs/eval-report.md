### 口径边界

- 问题由Agent根据既有NHS公开小节编写，未经独立医学审核；部分小节与旧题复用，不是全新盲测或真实顾客日志。
- 这是检索排序指标，不是医疗正确率、禁忌拦截率或药店端到端成功率。资料仍为仅检索、待审核。
- 单题单个正向段落金标不保证穷尽所有相关段落，存在标注偏差。
- 题目与金标运行前固定，本轮未调权重、阈值、切分或重排模型。
- Manifest中的Hit@5 Wilson区间假设题目独立；同一主题内题目相关，不能据此宣称线上显著提升。
- 旧小样本结果及混合粒度验证集不再作为正式报告口径；200题虚构回归结果单列。
