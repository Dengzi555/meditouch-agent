# 日常健康问答扩展（2026-11-02）

最新实现：补充5份原件已构建17个待审核检索单元，现真实检索总计30个；会话与追问续接已实现。详见 [资料入库与咨询续接](ingestion-and-consultations.md)。以下13单元等描述为首批接入记录，未包含后续补充。

用户确认面向普通用户、病人及家属，希望加入感冒、发烧等日常问题。原来的高血压食养只作为第一条验证链路，产品范围扩展为「日常健康问答与就医信息」。

## 本批接入范围

保留高血压食养9个章节检索单元，新增4篇中国疾控中心网页正文，各为一个完整检索单元，共13个。采用整篇科普正文以保留人群、否定词和限制条件，没有把症状直接映射为疾病，也没有增加自主诊断、处方或药物剂量规则。

| 方向 | 可检索内容 | 当前限制 |
| --- | --- | --- |
| 普通感冒、流感 | 病原与典型表现区别、常见误区、预防 | 症状差异不能确诊病原 |
| 发热、咳嗽 | 呼吸道疾病相关科普、文中就医信号 | 发热是症状，尚无覆盖全部原因的分诊流程 |
| 鼻塞、流涕、咽痛 | 上呼吸道相关症状介绍 | 未接入各症状的独立完整诊疗指南 |
| 高血压 | 既有食养章节 | 仍为待审核，非完整慢病管理 |

下一批建议腹泻/便秘、消化不良、过敏性鼻炎；这些方向尚未收集、接入或验收。儿童、孕产妇、老人及有基础病者的适用条件必须单独审核；本轮不宣称已完成特殊人群问诊。

## 工程实现和验证方式

`meditouch/web_knowledge.py` 只抽取 `#articleCon` 正文，排除导航、脚本和页脚；每次读取校验原件与正文哈希。HTML没有PDF页码，以网页正文选择器和提取文本坐标定位。`EvidenceService` 默认真实检索合并既有PDF和这批网页；自定义PDF语料路径不会自动混入本地网页包。包未下载时可运行旧语料；存在但损坏时检索失败，禁止静默使用变更内容。

四篇网页全部固定为 `pending` / `generation_allowed=false`。来源机构审核不等于本项目对适用范围、版本和引用单元的审核；改manifest不能自动批准这些网页。新资料暂时只允许原文预览。尚未建立这批资料的正式审核发布流程。

```powershell
python -B -m meditouch.web_knowledge collect
python -B -m meditouch.web_knowledge check
.\.venv-agent\Scripts\python.exe -B -m unittest tests.test_web_knowledge tests.test_agent_graph tests.test_agent_http -v
```

网络采集只在显式 `collect` 时运行；查询不在线抓取。完整网页作为单元是第一版折中，后续可按问答/章节切分，再评估准确率和上下文长度。

新增 `eval_data/common_respiratory_questions.json` 为人工编写的合成开发用例，非真实病人记录，非医学审核标准答案。包括正常科普、需要追问、证据不足、冲突夹具、工具失败；个人症状追问、紧急情况优先处理及语义级冲突检测仍需实现与独立验收，不能把用例清单当作已通过。
