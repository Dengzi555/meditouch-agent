# 本地 API 配置

点击左下角“本地门店”头像，选择“API 配置”。侧栏收起时仍可点击头像。

| 分组 | 配置 | 当前用途 |
| --- | --- | --- |
| 文本模型 | Base URL、模型名、API Key | 提取顾客需求、选择受限话术 |
| 视觉识别 | 独立 Base URL、视觉模型名、API Key | 药盒图片文字预填 |
| 公开知识与搜索 | NHS、易源、联网搜索密钥及公开查询开关 | 知识检索链路的可选配置，是否使用由当前执行图决定 |

## 保存与生效

- 页面从后端读取当前有效配置，密钥字段只返回是否已配置，绝不回传原密钥。
- 密钥输入框留空表示保留原值；点击“清除”并保存才会移除密钥。
- 点击“保存配置”后，当前有效 API 设置统一写入服务端项目根目录 `.env`，保留其他配置项和注释。首次保存也会迁入启动器已加载的 API 设置。
- `.env` 使用明文保存，已加入 `.gitignore`；不会将密钥保存在浏览器 localStorage/sessionStorage。
- 写入采用临时文件加原子替换，写入失败时不更新进程配置。
- 保存成功后从下一次请求使用新值；已经开始的任务不保证切换，因此应先完成或停止当前任务。
- `python server.py` 启动时自动加载 `.env`。已保存的 API 字段优先于旧 DPAPI 启动器默认值，空值也会覆盖，避免清除后旧密钥被自动恢复。其他字段保持进程环境变量优先。
- 当前只持久化配置，不调用供应商进行连通性测试；“已配置”不代表模型访问验证通过。

## 接口与访问限制

- `GET /api/settings`：返回非敏感配置和密钥配置状态。
- `POST /api/settings`：`{"values":{"MED_AGENT_MODEL":"model-name"}}`，仅允许登记的 API 配置字段。
- 两个接口都要求本机来源与本机 Host；拒绝远程客户端、跨站 Origin 和带隧道代理标识的请求。通过公网隧道访问的用户不能修改服务端密钥。
- 响应使用 `Cache-Control: no-store`；错误信息不包含提交内容、密钥或文件内容。

## 验证

```powershell
python -B -m unittest tests.test_settings -v
```

覆盖密钥脱敏、保留原值、主动清除、重启读取、无效字段拦截、跨站与代理访问拒绝以及原子写入失败。浏览器验收使用临时 `.env` 和虚构密钥，不写实际配置。
